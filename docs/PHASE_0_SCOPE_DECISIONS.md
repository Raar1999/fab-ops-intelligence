## Additional Phase 0 scope rulings (no contradiction, recorded for clarity)

- **Console entry points** (`fabops-build`, `fabops-investigate`) are included: pure packaging metadata over existing `main()` functions, per ADR-009. No new CLI module, no argument parsing added.
- **CI workflow file** (`.github/workflows/ci.yml`) is included: it encodes exactly the locally verified commands (editable install → `pytest -q` → delete DB → rebuild → re-test). It cannot execute until the repo has a GitHub remote; noted in completion doc.
- **Committed generated artifacts** (`data/fab.db`, executed notebook, figures) are regenerated **once, at the end of the code changes**, in a dedicated `chore:` commit, so each code commit stays focused and the final tree is fully self-consistent. Intermediate commits may carry a momentarily stale notebook; the completion doc records this.
- **Figures** will be re-rendered by the notebook execution with the current matplotlib; bytes change, content is chart-identical (same data, same code paths). Recorded in the baseline comparison.
- **`data/generate_fab_db.py` is not touched** in any way — generator changes are Phase 1 by definition.
- **`sql-mastery-handbook/` and the PDF are outside this repository** and outside Phase 0 scope (bundle-level `README_BUNDLE.txt` quickstart lines are updated for accuracy only).
- **Test count changes 26 → 27**: adding `v_gate_etch_runs` extends the parametrized queryable-view check. Documentation references to "26 tests" are updated; this is a hygiene-driven, explicitly justified behavioral delta.
- **One line is added to the investigation banner** labeling the run as the demonstration RCA (gate Step 6 honesty requirement). This is the only intended stdout change in Phase 0 and is diffed explicitly in the baseline comparison.
